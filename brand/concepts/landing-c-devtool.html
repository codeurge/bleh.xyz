What you get

The whole feed. No tiers.

Planned for the first releases and currently in development.

Live websocket

Trades, books, bars and order-flow analytics on one stream, for every market on the first venue from day one.

Order-level books, no embargo

Order-by-order (L3) books from nodes we run, with depth derived from them. Nothing delayed or held back.

History back to launch

A versioned archive backfilled to each venue's earliest public data. Query it, or download all of it.

Signed and verifiable

Each block is signed by the node that published it. Manifests are timestamped on Bitcoin, so anyone can check.

Torrent, IPFS and Arweave mirrors

The same content-addressed archive over HTTPS, BitTorrent, IPFS and Arweave. Any copy is as good as ours.

SDKs and compat layers

Rust, Python and TypeScript SDKs, plus compatibility layers so existing market-data clients can switch with little change.

Connect

One socket. No API key.

Subscribe by instrument and kind. Every record carries its source, lineage and a block signature, so you never have to take our word for it.

const ws = new WebSocket("wss://live.bleh.xyz");

ws.onopen = () => ws.send(JSON.stringify({
  op: "subscribe",
  kinds: ["trades", "book.l3"],
  instrument: "BTC-PERP",
}));

ws.onmessage = (m) => {
  const rec = JSON.parse(m.data); // signed, with provenance
  console.log(rec.kind, rec.px, rec.sz);
};
import asyncio, json, websockets

async def main():
    async with websockets.connect("wss://live.bleh.xyz") as ws:
        await ws.send(json.dumps({
            "op": "subscribe",
            "kinds": ["trades", "book.l3"],
            "instrument": "BTC-PERP",
        }))
        async for msg in ws:
            print(json.loads(msg))

asyncio.run(main())
# any websocket client works

How it stays up

No takedown target.

Nothing in the pipeline belongs to someone who can ask for it back.

Independent sources

Our own venue nodes, US public swap dissemination and other on-chain venues. A source joins only if nothing upstream of it carries an exchange data contract.

Mirrors everywhere

Signed blocks that any relay can carry, and an archive on HTTPS, BitTorrent, IPFS and Arweave. It is CC0, so rehosting needs no permission.

Anchored on-chain

Manifest hashes are timestamped on Bitcoin. Anyone can prove a file is the one that was published, whoever served it.

Honest label: these are prices for the same economic exposure, discovered in the open. They are not exchange prices or official settlements.
