what you get

Planned for the first releases. Everything below is in development.

01 live websocket

One stream for trades, books, bars and order-flow analytics, covering every market on the first venue from day one.

02 order-level books, no embargo

Order-by-order (L3) books read from our own nodes. Depth is derived from them. No delay tier, no "pro" tier.

03 history from the start

A versioned archive, backfilled to each venue's earliest public data. Download all of it. Keep it.

04 signed + verifiable

Every block is signed by the node that published it. Manifests are timestamped on Bitcoin, so you can check instead of trust.

05 torrent / IPFS / Arweave

The same archive over plain HTTPS, BitTorrent, IPFS and Arweave. Content-addressed, so any copy is as good as ours.

06 SDKs + compat layers

Rust, Python and TypeScript SDKs, plus compatibility layers so existing market-data clients can switch with little change.

how it stays up

There is no takedown target, because there is nothing here that belongs to anyone else.

[1] sources

Independent by construction

Our own venue nodes, US public swap dissemination and other on-chain venues. A source joins only if nothing upstream of it carries an exchange data contract.

[2] mirrors

Copies you can't count

Signed blocks any relay can carry, and an archive on HTTPS, BitTorrent, IPFS and Arweave. The data is CC0, so rehosting it needs nobody's permission.

[3] anchors

Receipts on-chain

Manifest hashes are timestamped on Bitcoin. Anyone can prove a file is the one that was published, whoever they got it from.

Honest label: these are prices for the same economic exposure, discovered in the open. They are not exchange prices or official settlements, and we will not pretend otherwise.
