Prices are not a subscription. Bleh.

The legacy market-data giants charge a fortune to tell you what something costs. We'd rather shrug. bleh.xyz is futures-grade market data built only from open, independent price discovery: signed, mirrored, public domain, and yours to redistribute.

What you get

Planned for the first releases, all in development. No tiers, no seats, no "per display device".

01

Live websocket

Trades, books, bars and order-flow analytics on one stream, for every market on the first venue from day one.

02

Every order. No embargo.

Order-by-order books from nodes we run ourselves. Not delayed, not sampled, not held back for a pricier plan.

03

History since day one

An archive backfilled to each venue's earliest public data. Download the lot and keep it forever.

04

Signed. Check it.

Every block is signed by the node that published it, and manifests are timestamped on Bitcoin. Verify, don't trust.

05

Seed it yourself

HTTPS, BitTorrent, IPFS and Arweave. Content-addressed, so your copy is exactly as real as ours.

06

Plugs into your stack

SDKs for Rust, Python and TypeScript, plus compatibility layers so the client you already use can switch with little change.

# pip install websockets
import asyncio, json, websockets

async def main():
    async with websockets.connect("wss://live.bleh.xyz") as ws:
        await ws.send(json.dumps({
            "op": "subscribe",
            "kinds": ["trades", "book.l3"],
            "instrument": "BTC-PERP",
        }))
        async for msg in ws:
            print(json.loads(msg))   # signed, with provenance on every record

asyncio.run(main())

Good luck taking it down

There is no takedown target, because nothing here belongs to anyone else.

01 / SOURCESNobody's licence to pull

Our own venue nodes, US public swap dissemination and other on-chain venues. A source only joins if nothing upstream of it carries an exchange data contract.

02 / MIRRORSCopies everywhere

Signed blocks any relay can carry. An archive on HTTPS, BitTorrent, IPFS and Arweave. It's CC0, so rehosting it needs nobody's permission, including ours.

03 / ANCHORSReceipts on Bitcoin

Manifest hashes are timestamped on-chain. Anyone can prove a file is the one that was published, no matter who handed it to them.
