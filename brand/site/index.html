The problem

Prices are made in public. Then somebody fences them off.

A trade happens, the whole market learns from it, and a contract decides who may look. Receive licensed prices, or anything derived from them, and you inherit the contract. So does whatever you build.

Our considered response

We are not breaking the fence. We are measuring the same thing from the public side of it.

The answer

Same exposure. Open sources. Clean lineage.

The same economic risk now trades in places where every order is public. bleh.xyz reads those places directly and publishes what it sees, with the method attached.

On-chain order-book venues

Read from nodes we run ourselves, starting with every market on Hyperliquid: crypto, index, oil, metals, FX, rates and grains.

First source · in development

US public swap dissemination

Swap trades that US law requires to be published free of charge. They give rate curves, commodity swaps and options context.

Parallel lane · in development

More open venues, then agencies

Further on-chain venues, and public-domain cash-market and rates data from US agencies. Each one passes a public admission review first.

Planned

Honest label. These are prices for the same economic exposure, discovered in the open. Arbitrage keeps them close to exchange prices; the link is economic, not contractual. They are not exchange prices or official settlements, and we will publish the measured basis instead of hiding it.

What you get

The whole feed. No tiers.

Everything below is planned for the first releases and is being built in the open. None of it is live yet.

Trades with aggressor side

Trade-by-trade tapes for every market on each venue. The aggressor is native venue data, never inferred from the quote.

Order-level books, no embargo

Order-by-order books from our own nodes, with depth and top of book derived from them. Nothing delayed, nothing held back.

Bars, 1 second to 1 day

Time, tick, volume and range bars built from trades only. A gap is published as a gap, never quietly filled in.

Open order-flow analytics

Footprint, delta and CVD, volume profile and heatmaps, each with a versioned method you can read and recompute.

History back to the start

A versioned archive backfilled to each venue's earliest public data. Query it in place, or download all of it.

Signed per block

Each block's records hang off a Merkle root signed with secp256k1. Any relay or mirror can carry them; you check the maths.

Replay API

Play any archived day back as if it were live, in order, at the speed you choose. Backtests and production read the same records.

SDKs, compat layers, MCP

Python, TypeScript and Rust SDKs, compatibility layers for the tools you already run, and an MCP server so agents can ask too.

How it works

Nodes in. Signed blocks out. Copies everywhere.

A short pipeline with no licensed input at one end and no single host at the other.

  1. 01 · Nodes

    Read the venue directly

    Two of our own nodes on two providers read every market. Disagreement between them is an integrity alarm.

    • own venue nodes
    • public swap prints
  2. 02 · Signed blocks

    Sign what was seen

    Each stream's records in a block become Merkle leaves. The root is signed, so any single record can be proven.

  3. 03 · Gateway + archive

    Stream it and keep it

    A websocket gateway for live data and replay. A static Parquet archive you can query in place with the tools you have.

    • websocket
    • replay
    • Parquet
  4. 04 · Mirrors

    Let anyone carry it

    The same content-addressed files over three independent networks. Every copy verifies against the signed manifest.

    • CDN
    • BitTorrent
    • IPFS
Anchored on Bitcoin. Each day's manifest is hash-chained, signed and timestamped, so anyone can prove a file is the one that was published, whoever served it.

    Developers

    One socket. No API key.

    Subscribe by instrument and kind. Every record carries its source, its lineage and a path to a signed root, so you never have to take our word for it.

    • Python, TypeScript, Rust. The same model in each: subscribe, verify, replay.
    • Query the archive where it sits. Static Parquet behind a CDN, readable by DuckDB, Polars or anything that speaks HTTP range requests.
    • Bring your existing client. Compatibility layers are planned so current market-data code can switch with small changes.
    • Agents welcome. An MCP server exposes the same live, history and replay calls to tools.

    Why it can't be taken down

    There is nobody to send the letter to.

    Takedowns work on things that are licensed, centralised or secret. The design avoids all three.

    1. 01

      Nothing upstream is licensed

      A source joins only if nothing above it carries an exchange data contract. Each admission is a public record.

    2. 02

      The data is public domain

      CC0 means rehosting needs no permission from anyone, including us.

    3. 03

      Every copy is the original

      Files are content-addressed and manifests are signed, so a mirror you have never heard of is as good as ours.

    4. 04

      The record is anchored

      Manifest hashes are timestamped on Bitcoin. History cannot be quietly edited, by a critic or by us.

    FAQ

    Fair questions.

    Can I use it today?

    No. This is an early preview of a project in development. Nothing is live, there is no endpoint to connect to, and the code samples on this page are sketches. The repository is public, so you can watch it get built or help.

    Is this exchange data?

    No, and it never will be. It contains no exchange-licensed feed and nothing derived from one. It is data for the same economic exposure, collected from venues and public sources where that exposure trades in the open.

    How close are the prices to the exchange's?

    Arbitrage keeps them close, but they are proxies and are labelled as proxies. Measuring that basis and publishing it is on the roadmap. Do not use these as official settlements or to mark positions held at an exchange.

    What does "tape, not benchmark" mean?

    Some markets are thin. Their trades are real and worth recording, but one small print should not be mistaken for the price of wheat. Each market will carry a published liquidity grade so you can tell which is which.

    Can I redistribute it, resell it, or build a product on it?

    Yes. The data is dedicated to the public domain under CC0 and the code is Apache-2.0. You do not need to ask, pay or credit anyone.

    How do I know a mirror did not change the data?

    You verify it. Live records prove against a per-block Merkle root signed with secp256k1. Archive files check against a signed, hash-chained daily manifest that is timestamped on Bitcoin.

    Who pays for this, and is there a token?

    There is no token and there will not be one. Hosting funding and long-term governance are listed as open questions on the roadmap. The design keeps running costs low: static files, zero-egress storage, and mirrors run by anyone who wants one.

    Is this legal advice?

    No. We publish how each source was reviewed and what was admitted, so you and your counsel can judge the lineage yourselves.
