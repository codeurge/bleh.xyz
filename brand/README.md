# bleh.xyz brand

The logo is the name: a lowercase **bleh** whose **e** sticks its tongue out.
One small joke in a calm wordmark, so the data and docs can stay serious.

## Files

| File | Use |
|---|---|
| [logo.svg](logo.svg) | Wordmark for light backgrounds (ink) |
| [logo-light.svg](logo-light.svg) | Wordmark for dark backgrounds (cream) |
| [logo-mono.svg](logo-mono.svg) | One colour; the tongue becomes an outline |
| [mark.svg](mark.svg) | Square mark: favicon, avatars, app icons; legible at 16px |

All logos are drawn geometry, with no font dependency. The wordmark's ink
uses `currentColor`, so it can also be recoloured inline.

## Type

DM Sans for text and headings, DM Mono for code and data.

## Voice

Cheeky about legacy market-data giants in general, precise about the
product. Never name or parody a real company, and never invent statistics.
Poster style (big condensed type, tape yellow) is fine for launch posts and
stickers. The order-book face from concept 3 can serve as an in-product
status glyph.
